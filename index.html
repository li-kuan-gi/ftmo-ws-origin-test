如何判讀

「握手成功」：瀏覽器觸發 WebSocket open 事件，表示伺服器接受了這個頁面來源的 WebSocket 握手。這只證明傳輸層連線成功，尚未測試 MT5 加密初始化、登入或歷史 K 線請求。

「連線失敗」：可能是 Origin 被拒絕、Endpoint 不正確、伺服器不可用、TLS/DNS 問題或網路政策限制。瀏覽器通常不會向 JavaScript 公開握手失敗的 HTTP 狀態碼，因此單靠這個頁面不能斷定是哪一種原因。

請從已部署的 GitHub Pages HTTPS 網址執行測試。若直接以 file:// 開啟，測到的不是 GitHub Pages Origin。請勿在此頁輸入 MT5 密碼、Cookie 或 Token。
這是獨立的靜態診斷頁，沒有外部 JavaScript 套件、分析追蹤或帳戶登入功能。頁面只記錄連線狀態、時間、Close code 及訊息大小，不會顯示 WebSocket 訊息內容。
